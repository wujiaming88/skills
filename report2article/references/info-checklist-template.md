# 原子信息与双向校验模板

这份清单记录需要保持语义不变的独立信息。它不是原文逐句复制，也不把重复措辞算成新信息。

## 1. 转换前建立基线

给每条独立信息分配稳定编号：

```markdown
## 对象 O
- [ ] O01：对象全名｜允许简称｜适用范围

## 事实 F
- [ ] F01：事实内容｜主体｜时间｜限定条件｜来源位置

## 数据 D
- [ ] D01：数值｜单位｜时间范围｜统计口径｜来源位置

## 判断 J
- [ ] J01：判断原义｜强弱：可能/倾向/已经/必然｜归因主体｜来源位置

## 来源与链接 L
- [ ] L01：来源名称｜URL｜支撑 F/D/J 编号
```

同一 URL 重复出现时只计一个 L 编号，但要记录它支撑的全部信息。相同文字若处于不同时间、范围、口径或归因下，必须拆成不同编号。

## 2. 建立文章映射

编辑完成后，为每条编号记录文章落点：

| 编号 | 原报告信息 | 文章章节/段落 | 表达变化 | 核对结果 |
|---|---|---|---|---|
| F01 |  |  | 合句/拆句/去重/顺序调整 |  |
| D01 |  |  | 单位与口径是否原样保持 |  |
| J01 |  |  | 判断强弱是否一致 |  |
| L01 |  |  | 正文/脚注/图注 |  |

一条信息可以映射到一个自然段、表格单元格或图注；不能只因为对象名称出现过，就判定该对象的所有信息已覆盖。

## 3. 五维正向检查

| 维度 | 通过标准 | 主要方法 |
|---|---|---|
| 对象 | 名称、范围和简称无错配 | 字面搜索 + 对读 |
| 事实 | 每条 F 编号有准确落点 | 逐条映射 |
| 数据 | 数值、单位、时间、口径一致 | 字面搜索 + 逐条映射 |
| 判断 | 原义、强弱、归因一致 | 语义对读 |
| 来源 | 唯一链接保留，支持关系未错配 | URL 搜索 + 对读 |

## 4. 反向溯源检查

从文章第一段开始逐段反查：

- 每个事实、数字、关系和判断能否指向一个 F/D/J 编号？
- 标题、导语、过渡和结尾是否暗示了清单外的新结论？
- 去重是否只删了重复表达，而没有删掉不同限定条件或不同来源？
- 图表的数据、标签、比例和图注能否回到 D/F/L 编号？
- 概念图是否标为“示意图”，且没有制造报告未支持的关系？

找不到来源的内容要删除或改为明确的编辑建议，不能留在成稿里。

## 5. 独立二次派生

长报告必须重新打开原报告，不看第一次清单，从头二次派生 O/F/D/J/L 全量编号。比较两份清单：

- 第二份多出的信息，补进基线与文章。
- 两份表述不同但实际相同的，核对限定条件后合并。
- 无法确认是否重复的，按两条保留，避免误删。

二次派生必须覆盖全部原子信息，而不只是对象名称。

## 6. 交付口径

固定报告：

```text
信息校验：O 个对象 / F 条事实 / D 个数据点 / J 条判断 / L 个唯一链接，全部可追溯 ✅
```

某一类为 0 时如实写 0。只有所有编号都完成正向覆盖和反向溯源后，才能写“全部可追溯”。
