# 原子信息与双向校验模板

## 1. 建立基线

每条独立信息有稳定编号，不逐句复制，不把重复措辞算新信息：

```markdown
## 对象 O
- [ ] O01：对象全名｜允许简称｜适用范围
## 事实 F
- [ ] F01：事实内容｜主体｜时间｜限定条件｜来源位置
## 数据 D
- [ ] D01：数值｜单位｜时间范围｜统计口径｜来源位置
## 判断 J
- [ ] J01：判断原义｜强弱｜归因主体｜来源位置
## 来源与链接 L
- [ ] L01：来源名称｜URL｜支撑F/D/J编号
```

记录冻结母稿路径、版本和公开边界、首次原始计数。同一URL只计一个L但记录所有支撑关系；不同时间、范围、口径、归因分开编号。独立二次提取用自己的编号和粒度，不看首次清单或成稿。

## 2. 记录去向及语义映射

在现有清单/`article-traceability.md`增加去向与理由，不生成第三套完整清单：

| 首次编号 | 二次编号 | 母稿位置与完整语义 | 内容去向与准确落点 | 处理理由 | 差异及依据 | 核对结果 |
|---|---|---|---|---|---|---|
| F01 | F02、F03 | 主体/限定/归因 | 正文段落 | 核心事实 | 一对多：条件逐项完整 | |
| D01、D02 | D04 | 单位/期间/分母 | 表格及脚注 | 精确比较 | 多对一：口径完整 | |
| J01 | J02 | 判断原义与强弱 | 正文邻近主张 | 必要边界 | 判断不漂移 | |
| L01 | L01 | URL及支撑关系 | 公开来源区锚点 | 便于追溯 | 唯一URL与支持关系一致 | |

实质信息只能映射正文或公开补充材料；仅生产过程可映射审计，写明为何不影响读者判断。抓取过程与由其形成的证据缺口分开处理。不能因“非主线”改成内部，关键限制不能只放附录。对分类有争议先保持公开，回母稿核验。

允许一对多、多对一，不强迫同编号、同类别粒度、同总数；逐项确认主体、期间、单位、分母、样本、限定、来源、归因与强弱，不能只写“粒度不同”。

## 3. 正向覆盖

逐项核对两份清单的独立信息：对象名称范围不错配；F限定完整；D数值单位日期口径一致；J原义强弱归因一致；L保留唯一链接与支撑关系。实质信息公开可访问，生产过程在审计有合理落点。对象名出现、总数相同、链接集合相同均不能替代语义覆盖。

## 4. 全文反向溯源

从头到尾逐段反查公开内容，包括标题、导语、正文、过渡、结尾、图表、图注、附录。每项事实、数字、关系和判断回到母稿与编号；去重不丢不同限定，概念图不制造事实感。无来源内容删除或列在独立编辑建议，不留成稿；研究缺口退母稿，不能编辑补事实。

## 5. 独立二次派生与补漏

长文执行长文协议，保留两份原始清单和计数。任一方漏项，在原文件补漏区追加新编号及证据，补公开内容和映射，不覆盖原计数；等义拆分记录一对多或多对一依据，不重写清单凑数。无法确认是否重复按独立信息保留，差异未解不得PASS。不生成第三/第四套完整基线。

## 6. 交付口径

在独立交付说明报告“信息校验：O个对象 / F条事实 / D个数据点 / J条判断 / L个唯一链接，全部可追溯”，不写入文章首尾。采用首次声明粒度及有依据补漏，审计保留双方原计数和差异，不冒称原清单同数，某类0如实写0。仅在独立提取完成、差异全解释、实质信息公开全覆盖、全文反向溯源及阅读复验通过后使用此结论。
