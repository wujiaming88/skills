# 文章结构与章节设计

## 1. 确定一条读者主线

用原报告明确表达的主题或结论回答“读完应该理解什么”，再选择主线：时间线用于演变，问题递进用于机制与影响，对比用于可比方案，因果链只用于已证实因果，总分总用于多主题导航。其他结构只局部辅助；不凭空套战争、冲突或逆转叙事。完成时每节说明读者问题与信息落点。

## 2. 先安排连续论述

导语从重要事实、变化或问题起笔；背景拆入首次需要的位置。主体按认知顺序推进，同一问题的信息合并，不因对象不同机械分章；同一对象可承担不同论述作用，不重复同一信息。已有结论可以前置，但立即接证据；未明确关系只能导航，不能把并置写成因果、竞争或趋势。速查表用于导航，不代替完整信息。

完成时相邻段落无需依靠新增小标题也能看出承接关系。

## 3. 筛选标题

按主文件的层级规则逐个检验：“去掉这个标题，是否更难理解结构或定位内容？”只有一小段的分节优先合并，过载章节按真实问题拆分；不追求等长、同句式或固定数量。信息清单、任务分块和写入次数不生成公开标题，删除标题后衔接段落，不批量替换为粗体标签。短文可以没有子标题，多主题周报保留跨主题查找入口。完成时同级语义层级一致，标题确有导航收益。

## 4. 收束主问题

回到已有结论、影响或未决问题；没有结论不代替作者下判断，也不必另写总结。与主线分离的详细实施方案按信息去向放公开补充区；来源与正文收束分开。完成时最后一个实质段落结束论述，不引出新的任务汇报。
