# 超长报告处理协议

## 触发条件

对象不少于8个、正文约6000字或8000 token以上，或任何读取截断/分页未完时执行。

## 1. 完整读取与信息账本

分段读到原报告末尾，记录总行数或末节，确认不是工具返回上限。记录同一冻结输入路径、版本及公开边界，PRIVATE_INTERNAL不交编辑；不能为逃避保真把应公开研究转成内部。按信息模板记录O/F/D/J/L原子信息及总数、限定与去向。对象数不能证明对象内部事实数据判断完整。

同一编辑者连续阶段，只有母稿与所用规则SHA均未变、前次完整读取证据齐全且所需上下文确实仍在时，才可按需回查未变规则/输入，不无条件重新全套装载。在既有映射进度区记录执行者、路径/SHA、前次读取范围及末尾定位、上下文可用依据和本次回查范围；同session或SHA相同本身不证明已掌握内容。换人、缺上下文、版本变化或读取证据不足时，恢复完成当前工作所必需文件的完整读取；未变有效证据不因此全量重做。新到的第二清单仍须完整读完，协调时逐项打开两侧条目及直接引用。该复用仅限中间装载，第6节编辑者和父级最终全文验收仍完整执行。

## 2. 全局结构

写正文前明确：一句话主线、论述顺序、每部分读者问题、覆盖编号、语气与术语、图表位置和支撑编号。先组织连续论述再决定最终标题；信息移动同步更新映射。完成时全文有统一结构，不是各分片拼接。

## 3. 分块编辑与落盘

每块是完整论述单元，不固定字数切割；一个公开章节可以由多块完成，分块不生成标题。每块完成立即写文件并检查增长和尾部；写前回看相邻开头结尾，保持语气与衔接。导语和收束可最后统一定稿，但事实判断仍关联编号。分块只防截断，不降低深度或丢内容。

## 4. 逐块销账

在现有映射记录进度，例如“O 3/8｜F 17/46｜D 8/20｜J 5/14｜L 6/12”，以及本块编号、去向和准确落点；进度不进入正文。主要信息只记主要承载处，图表图注记录D/L。实质信息须公开，过程记录须有分类依据；缺号、错配、风险隐藏或判断漂移先修再进入下一块。

## 5. 独立二次派生与协调

复核者仅读同一冻结母稿与公开边界，不看首次账本或成稿，从头到尾独立提取全部原子信息。资源允许时与编辑并行但不扩大既有并发；已看过首次清单不得冒称盲提取。两份清单完成冻结后再协调。

父级中间Phase1仅核交接完整性、两原清单冻结版本、写权已交回及明确阻断项；完整性须确认文件清单、读取尾部/截断状态与版本对应，不以文件存在或大小代替。已有具体疑点即读取受影响内容，不在协调前无条件再做一次全文语义终审，也不把中间检查标成文章PASS。确认二次提取者交回、两原清单冻结后，由原编辑继续协调；新编辑接管先确认旧写者结束并交回唯一写权。该门控不减编辑者逐块自检及第6节双方最终验收；周报角色交接另遵守本次指定handoff，不另造等待或发布流程。

保留`article-baseline.md`和`article-second-pass.md`原始清单、编号、计数，逐项差异及新版落点写既有`article-traceability.md`，不造第三/第四套完整清单，不重写凑数。紧凑引用与映射写法执行 `info-checklist-template.md` 第1—2节；只有取得相应文件唯一写权才可追加补漏。

- 粒度不同：记录一对多、多对一和母稿位置，逐项核对主体、期间、单位、分母、样本、限定、来源、归因与强弱。
- 任一方漏独立信息：在该原文件补漏区追加编号与证据，补文章和映射，不覆盖原计数或声称原本没漏。
- 总数同而内容不同：逐项处理，不以同数放行。
- 表述、去重或公开边界有争议：回母稿解决；无法确认等义不合并，差异未解BLOCKED。
- 输入或文章变化：保留旧审计，新版本重验受影响内容，最终结论仍覆盖新版完整母稿与文章。冻结母稿未变且已有独立双清单的文章修订，可复用原清单，保留旧映射并补充新版准确落点；不能声称重新做了盲提取。

## 6. 全文验收与阅读复验

编辑者完成协调后完整读取最终母稿的允许公开内容、两份清单、映射和文章全文；父级最终也须完整读取冻结母稿、两份清单、映射与文章并验收，不能只看done、差异摘要或沿用中间Phase1结论。私密内容仍不传给编辑，双方依各自获准范围审查。

正向：两份清单每项经已解释映射均有准确去向，实质信息在正文或公开补充材料，过程在审计有依据，所有差异闭合、未销账0。反向：从头到尾检查正文、标题、过渡、结尾、附录和配图，每项事实关系判断回到母稿，不以局部抽查替代全文。

执行`reading-review.md`完整阅读；修改后更新受影响映射并复验，最终检查涵盖全部新版。公开附录的链接、折叠和引用锚点需在交付渠道可访问。

对象名、精确数字、日期、URL可用`grep -nF -- "原文" article.md`辅助；退出1只代表无字面命中，不自动代表工具错误或语义漏项。判断强弱、因果、归因、限定及去重只能语义对读。

完成标准：两份原清单留存，逐项差异有证据，实质信息全公开覆盖，过程去向合理，全文反向溯源通过，阅读问题关闭，未销账0且无新增事实和判断漂移。校验计数仅在独立交付说明汇报，采用首次粒度及有依据补漏，不冒称两份原清单同数。
