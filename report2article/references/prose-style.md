# 读者型表达与风格

## 1. 做等义编辑

允许改主动/被动语态、拆长句、合并重复主语、删除空转套话、重排信息、统一简称及增加纯导航。保留数字、单位、日期、主体、范围、归因、判断强弱和不同限定；不能把相关写成因果、局部写成普遍。术语只用母稿已有解释，不为通俗自行补背景、动机、情绪或比喻。完成时每段含义和证据边界与母稿一致。

## 2. 统一风格与段落

整篇只选一个主风格：专业通俗重最短必要解释，技术深度重机制与限定，媒体叙事重事件但不制造冲突，周报速读重时间变化和主题导航。未指定时专业、清楚、克制，不居高临下或故作轻松。

用具体主语与动词，先关键事实再条件细节，限定紧邻主张。长短句交替，一段一个中心，不切成大量单句段或每段模板化总结。首次全称后用无歧义简称，专名大小写准确。过渡只给阅读方向，不增加结论。完成时各块语气一致、段落自然承接。

## 3. 清理报告腔与重复

删改不承载独立信息的“值得注意的是”“需要指出的是”“不难发现”“随着……发展”“进行了相关动作”等。先检查是否含时间、范围、程度、归因或态度，有则保留其含义。相同信息不在正文、表格、结尾重复解释；不同限定不是重复。

例：把“谷歌方面在本周进行了一次产品发布动作……报告认为这可能推动生态发展”写成具体的发布事实与“报告认为，这可能推动生态发展”，保留“可能”和归因。

## 4. 清理首尾并保留证据边界

按主文件步骤4安排有效首尾。逐句问：“帮助读者理解主题、证据或结论，还是解释作者完成了什么工作？”前者按需公开；后者留审计或交付说明。方法不能一律当杂质：非实测、样本局限及证据缺口影响判断时仍须简明披露。全文方法边界集中一次，局部限制随主张，不在首尾反复列免责声明。正文结束后不叠加工作汇报。

## 5. 选择表达形态

叙事与机制优先自然段，真正并列可扫描的内容用列表，精确比较用表格，长论述不塞进单元格。加粗只突出关键术语、数字或结论，通常一段不超过一两处；不能将删掉的小标题全变成加粗标签。引用紧邻观点，链接文字说明来源，不连续堆裸URL。完成时标题、列表、表格均有阅读收益，不只是格式整齐。
