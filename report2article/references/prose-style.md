# 读者型表达与风格

目标是在语义保真的前提下进行真正的编辑：句子可以重写，信息不能漂移。最终文字应像编辑理解材料后讲给读者听，而不是把报告换一套标题重新粘贴。

## 编辑边界

### 允许

- 等义改写，主动语态与被动语态互换。
- 拆分信息过载的长句，合并主语和信息重复的短句。
- 删除不承载独立信息的套话、重复限定和重复结论。
- 调整信息顺序，把结论、事实或限定条件放到更容易理解的位置。
- 统一同一对象的名称；首次写全称，后文使用无歧义简称。
- 增加纯导航句，帮助读者理解章节切换。

### 不允许

- 删除独立事实、限定条件、反例、来源或不确定性。
- 改变数字、单位、日期、主体、对象范围和判断强弱。
- 把时间先后写成因果，把相关写成必然，把局部比较扩大为普遍结论。
- 用常识补齐原报告没有解释的术语、背景或动机。
- 为了“有人味”加入作者没有表达的情绪、评价、比喻或立场。

## 默认风格：专业、清楚、克制

用户没有指定平台或文风时，使用以下默认值：

- 面向对主题感兴趣但不掌握全部上下文的读者。
- 保留必要专业词，避免无意义术语密度。
- 语气可信而不居高临下，不喊口号，不故作轻松。
- 先给读者方向，再展开证据；先写具体动作，再写抽象影响。

用户指定“媒体稿、技术深度稿、周报、公众号”等风格时，可以调整节奏和语气，但不能移动事实边界。

| 风格 | 结构与节奏 | 表达重点 |
|---|---|---|
| 专业通俗（默认） | 先结论后证据，段落适中 | 术语少而准确，解释最短必要背景 |
| 技术深度 | 机制递进，保留完整限定条件 | 术语准确，代码、参数和边界不简化失真 |
| 媒体叙事 | 用事件或变化开篇，节奏更强 | 具体动作优先，不制造戏剧冲突 |
| 周报速读 | 先给本期导航，再按主题展开 | 强调时间、新变化和原报告判断 |

整篇只选一个主风格。可以因内容调整段落密度，但不要在新闻腔、学术腔和口语化表达之间来回切换。

## 句子与段落

- **主语明确**：优先写“谁做了什么”，避免连续无主语句和多层“由……所……”。
- **动词具体**：写“发布、收购、开源、降价”，少写“进行了相关动作”。
- **信息前置**：把关键动作或结论放在句首，限定条件紧跟对应信息，避免读到句末才知道重点。
- **长短交替**：复杂信息用完整句解释，关键结论可用短句收束；不要连续制造口号式短句。
- **一段一意**：每段有一个中心，换问题就换段。不要为了“短”把一个完整论证切成许多单句段。
- **段首定位**：需要时用首句说明本段角色，但避免每段都写模板化总结句。

## 去掉报告腔

删除或改写不承载信息的表达：

- `值得注意的是`、`需要指出的是`、`不难发现`。
- `随着……的发展`、`在……的大背景下`、`在当今时代`。
- `进行了……的动作`、`起到了……的作用`、`在……方面`。
- 重复出现的`本周`、`该公司`、`从某种意义上说`。

删前要问：“这部分是否包含时间、范围、程度、归因或态度？”包含就不能当作套话删掉。

## 术语与解释

- 首次出现时写“全称（简称）”，后文统一用简称。
- 报告已经给出解释时，将解释压缩到读者理解所需的最短形式。
- 报告没有解释时，保留术语并避免假装解释；必要时把补充说明列为编辑建议。
- 产品名、机构名、版本号和专有大小写保持准确。

## 排版

- 叙事、演变和因果优先用自然段；只有真正并列、可扫描的内容才用列表。
- 表格适合精确比较，不适合承载长论述。单元格过长时改回正文。
- 加粗只标记真正关键的术语、数字或结论，一段通常不超过一两处。
- 引用应紧邻对应观点，链接文字要说明来源是什么，避免连续裸链接。

## 示例

**编辑前：**

> 值得注意的是，谷歌方面在本周进行了一次产品发布动作。谷歌在本周发布了 Vertex AI Agent Builder。据报告，该产品的定价方面是每千次调用 2 美元。报告认为，这可能推动 Agent 生态的发展。

**编辑后：**

> 本周，谷歌发布 Vertex AI Agent Builder，定价为每千次调用 2 美元。报告认为，这可能推动 Agent 生态发展。

这里合并了重复主语和“本周”，删除了空转措辞，但保留了主体、产品、时间、价格、归因和“可能”这一判断强度。
