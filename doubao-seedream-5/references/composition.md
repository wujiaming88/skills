# 构图决策与阅读顺序

每张图确定三件事：一个主构图原型、一个灵动动作、三层阅读顺序（第一焦点 → 第二阅读层 → 最终收束）。I2I 默认延续参考图骨架，用户要求创作、重排、改版或重构时才更换。

## 构图原型

| 原型 | 适合场景 | 核心骨架 | 提示词发展方向 |
|---|---|---|---|
| 非对称主视觉 | 商品、人物、IP、品牌海报 | 主体偏轴放大，文字在对侧平衡视觉重量 | 陪衬元素、局部光影、边缘节奏 |
| 字图咬合 | KV、封面、潮流海报 | 标题与主体穿插、环绕、承托或局部叠压 | 字形变化、字图连接、层次关系 |
| 对角线动势 | 活动、运动、年轻化传播 | 主体和信息沿斜向路径推进 | 飞溅、轨迹、飘带、速度细节 |
| 环形围合 | IP、节庆、活动主视觉 | 主体居中，信息和装饰沿弧线围合 | 节点、图标、环绕节奏 |
| 叙事拼贴 | 社媒、旅行、时尚、手账 | 主图与不同景别的辅助照片共同讲述一个场景，形成大小跳跃和层叠 | 照片角色、尺度节奏、语义连接、适量材质；必须是复杂分层的叙事拼贴，严禁简单平铺 |
| 主图卫星 | 穿搭、美妆、人物 Plog | 一张主图承担第一焦点，2–4 张细节图围绕主图形成证据与补充 | 主辅尺度、细节选择、视线回环 |
| 编辑式非对称网格 | 时尚、设计、城市生活 | 隐形网格组织照片与文字，局部跨栏或越格形成节奏 | 裁切、跨栏、留白、栏目小字 |
| 胶片接触印样 | Plog、旅行、日常记录 | 连续小格以时间、地点或动作变化串联，保留一个重点格 | 镜头顺序、编号、选片标记、胶片节奏 |
| 电影分镜条 | Vlog、探店、教程 | 远景、中景、特写或动作、反应依次展开 | 景别变化、时间推进、转场与收束 |
| 满版场景细节窗 | 松弛日常、旅行、探店 | 一张真实场景铺满画面，局部细节窗补充人物、物件或动作 | 场景氛围、窗口位置、局部呼应 |
| 物件标本板 | 穿搭拆解、美妆产品、清单 | 核心物件与配件、色样、质地或注释形成有序陈列 | 物件关系、色样、细节标注、呼吸感 |
| 对比联图 | 测评、教程、造型变化 | 双联或三联并置前后、不同方案或不同效果 | 对齐关系、差异焦点、简明说明 |
| 字体主视觉 | 金句、品牌态度、大字报 | 标题成为最大主体，图像承担气氛和语义 | 字体表现、色块、小型信息层级 |
| 编辑网格 | 专题页、宣传页、详情页 | 网格组织模块，重点元素局部越格 | 卡片内容、栏目、间距和阅读节奏 |
| 路径叙事 | 地图、攻略、教程、活动玩法 | 路线或编号串联多个信息节点 | 节点名称、路标、说明、互动细节 |
| 电影纵深 | 摄影、人像、场景、3D | 前景引导、中景主体、背景环境形成纵深 | 镜头、景深、光影、环境叙事 |
| 分栏版式 | 封面、介绍页、图文传播 | 上下或左右建立图文主区，以一处跨栏元素连接 | 分区比例、跨栏关系、标题与主体呼应 |
| 向心爆发 | 大促、赛事、强活动传播 | 主标题或商品位于中心，信息和图形沿放射方向展开 | 爆发节奏、价格或卖点层级、中心聚焦 |
| 满版阵列 | 多 SKU、IP 群像、系列陈列 | 重复元素铺满版面，以一处尺度、颜色或朝向变化建立焦点 | 阵列密度、特异点、标签与边缘节奏 |
| 压角留白 | 书封、文创、艺术与展览海报 | 主体或文字重量集中于一角，其余区域形成连续留白 | 角部重心、留白中的小型信息和克制动线 |
| 框架画中画 | 摄影、场景 KV、空间海报 | 门窗、植物、手或前景物形成天然画框，主体位于框内 | 框内外明暗、窥视感、前景虚实和视线聚焦 |

## 选择规则

1. I2I 默认延续参考图的空间骨架、主体位置和主次关系；用户有创作、重排、改版或重构需求时更新布局。
2. 单一核心主体优先选非对称主视觉、字图咬合、环形围合或电影纵深；多模块信息优先选编辑网格；流程、地图和教程优先选路径叙事。
3. 标准传播物料可用百分比分区；艺术海报、纯摄影和实验封面用主体关系、尺度对比和视觉动线表达。
4. 社媒封面的大标题位于首屏强阅读区，并具备手机缩略图识别度；摄影与 3D 场景按需加入景别、视角与前中后景。
5. 需要增强内容特征时叠加一个微型结构：长场景用 S 形路径引导，单主体用三分焦点承接留白，空间场景用门窗、植物或前景物形成框景，多商品或重复元素用一处尺度、颜色或朝向变化建立记忆点。
6. 单商品电商图优先非对称主视觉，多商品优先满版阵列，地图与教程优先路径叙事，书封与展览海报可选压角留白，场景摄影可选框架画中画，大促活动按内容选择向心爆发或对角线动势。

## 灵动动作

每张图选一个：超大标题、偏轴主体、局部越格、字图叠压、尺度突变、弧形路径、大片留白、非核心装饰出画。用“一个高密度区对应一个呼吸区 + 一组大中小尺度差 + 一个明确动势”形成设计节奏。

## 阅读顺序与信息落点

- 先写清三层：第一焦点、第二阅读层、最终收束位置。
- 非对称主视觉让标题与主体分居主轴两侧，次级信息在标题同侧下方；分栏版式让主副标题同组落在文字主区，行动信息在底部收束；字体主视觉让标题占主要画面高度，其他文字在边角或底部收束。
- 向心爆发让标题或卖点位于中心，卖点沿放射方向分层；路径叙事与编辑网格让节点、栏目按路径或网格依次展开；压角留白让次级信息沿角部重心展开；框架画中画与电影纵深让文字落在框外或清晰景深层。

## 量化约束

- 主标题是最大文字，通常占画面宽度约 45%–75%；副标题字号约为主标题的 35%–55%；小型图形文字 1–3 处，字号约为主标题的 15%–25%。
- 同类信息按语义成组，组间距大于组内间距。
- 每张图至少写清一组具体的前后或叠压关系：哪个元素在前、哪个在后、如何连接阅读动线。拼贴、字图咬合和电影纵深可用两组，极简与纯产品主图一组即可。

## 破模板感与惯性缺陷

- 每张图按风格安排一处轻量人工痕迹：手账与拼贴用微旋、折边、贴纸翘角或不等距排列；印刷与波普用套色偏差、网点或轻微错位；摄影用颗粒、轻微漏光或前景虚化；手绘用线条轻颤、描边变化或色块毛边。人工痕迹只作局部点缀，核心文字、品牌和主体保持清晰稳定。
- 装饰从主题语义提取（玩水发展水流与折射泡泡，登岛发展路线与印章），在同一母题下形态多样。
- 禁止：满屏同款气泡、同款贴纸或光斑；给每条小字套同质化、等比例的半透明底板或便签；机械重复同质化装饰符号。需要统一视觉语言的场景（UI、网页设计）例外，此时容器本身要统一。
- 装饰必须克制，一张图保证一个明确亮点，不为堆元素牺牲留白与呼吸感。
