# 意图到镜头与参数

依据：[官方 2.5 提示词指南](https://www.volcengine.com/docs/82379/2607689) 与 [任务类型约束](https://www.volcengine.com/docs/82379/2607688)。创意细节依用户意图调整，不固定套用所有字段。

## 先区分任务与素材用途

- “参考这段运镜拍新的产品广告”属于 `reference`；“把原视频里的产品改成这只杯子”属于 `edit`。
- “接着这段视频往后拍”属于 `extend`；“借用这个故事的感觉”不自动等于延长。
- 作为视觉主体、风格或故事板的图片用 `reference_image`；必须锁定第一帧/最后一帧才用 `first_frame/last_frame`。
- 同一张多宫格故事板仍计为一张图片，主要提供剧情参考；多张独立关键帧可更明确控制画面。不要保证故事板细节逐像素复现。
- 多个视频中必须说清哪一段待编辑/延长，其他素材各自负责什么。不要把所有素材笼统称为“参考”。
- 只有音频时可直接生成视频，2.5 不要求另配图片；用户要复用音色、节奏、旋律或对白时写清采用的部分。

## 组织提示词

短需求保持短；多镜头用时间轴或镜头顺序。推荐信息顺序：

官方建议中文不超过 500 字、英文不超过 1000 词，这是建议而非硬上限，不自动截断用户内容。提示词语言除中英文外，还支持西班牙语、印度尼西亚语、葡萄牙语、日语、马来语、泰语、阿拉伯语、越南语、韩语。

```text
素材：@图片1 提供产品外形和标识；@视频1 只参考运镜；@音频1 提供音乐节奏。
概述：主体 + 发生的事件 + 场景 + 风格。
0–3 秒：构图、主体动作、运镜、光线与声音。
3–5 秒：剧情推进与转场。
结尾：落点、必须保留的内容、需要避免的内容。
```

各类素材按输入顺序独立编号。官方示例同时使用 `@图片1/@图像1/@image1` 和 `@视频1/@video1`；一次请求选择一致、无歧义的写法。CLI 不在正文中自动替换文件名或编号。

保留用户逐字台词、品牌字样、指定镜头、动作先后与风格。用户已有完整提示词时，只补充必要的 API 约束和素材映射，不擅自重写创意。

声音可按官方指南写作：音乐 `()`、音效 `<>`、台词 `{}`、字幕 `【】`；对白也可置于双引号中。非中文台词注明语言，例如 `日语台词：{こんにちは}`。无需设置不存在的 `language` 参数。不要把“没有背景音乐”误转成 `generate_audio=false`，后者会同时去掉对白与音效。

## 参考生成

明确“生成一个新视频，参考某素材的某特征”，避免写成对原视频的替换指令导致误判。示例：

```text
生成全新产品短片。@图片1 提供茶杯的形状和花纹，@视频1 仅提供缓慢环绕的镜头运动。
清晨木桌上，热茶轻轻冒气；镜头从杯沿微距拉开，再环绕到侧面。保留杯身花纹。
背景是自然鸟鸣，不要对白和字幕。
```

`omni_reference_task_type=reference`；用户可指定比例和 4–30 秒时长。仅传文本时不设置全模态任务类型。

## 视频编辑

提示词明确“编辑视频/替换/增加/删除”等意图，并说明目标时间段、替换对象和不变项：

```text
编辑 @视频1：只在第 2–4 秒把桌上的杯子替换为 @图片1 的蓝色茶杯。
保留原有手部动作、镜头轨迹、背景、光照以及声音，其余时段保持原样。
```

`omni_reference_task_type=edit`、`ratio=adaptive`、`duration=-1`；至少一个 4–30 秒参考视频。时间段是提示词约束，没有独立编辑区间 JSON 字段。模型可能发生局部不符合预期的改动，必须检查成片，不能承诺其他像素绝对不变。

若用户要求把横版原视频改为竖版同时严格保留原视频，应说明编辑任务会锁定画幅；由用户决定改用参考创作还是对结果做后处理，不悄悄把 edit 变成 reference。

## 视频延长

提示词明确方向和衔接目标：

```text
向后延长 @视频1：衔接最后一帧的动作和原有音乐节拍，镜头继续向前推进，
人物走进阳光下的花园，最后停在花朵的近景。保持人物造型、场景光线与镜头运动连续。
```

`omni_reference_task_type=extend`、`ratio=adaptive`；至少一个参考视频。也支持向前延长。2026-09-18 实测：输入约 4 秒视频、设置 `duration=4`，前/后延长均返回独立的 4 秒新增片段，不包含原视频。用户说“再加 5 秒”时，区分新增片段时长与合并后的总时长，不承诺自动拼接。需要完整合并结果时，另做后处理并检查衔接。

官方推荐编辑与延长输入/输出使用 mov 以改善画面与声音衔接；默认交付兼容性优先时用 mp4，并说明取舍。不要自动把不兼容素材转换、裁剪或上传而改变用户预期。

## 多语言与多镜头

按镜头/时间片明确语言、说话者、台词和声音环境。对白长度应与时长匹配；过长文案优先精简或拆分，不通过 `duration=-1` 默默放大成本。30 秒为单次生成上限，超过上限可在用户需求范围内拆成多次生成，先说明片段数量与连续性限制。

可覆盖主体/运动/风格/白模渲染参考、多宫格分镜、关键帧、多素材成片、视频间过渡、画面/声音增删改和延长；它们由上述官方 content、task type 与提示词组合表达，没有额外未经证实的 API endpoint。
