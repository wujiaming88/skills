# Common failure playbook

仅在SKILL.md适用门通过后使用。本文件是症状索引，不维护第二套等待/恢复/终态流程；通用身份与交接读主文件第2节，等待/补缺/恢复读第3节，终态读第7节，helper边界读helper-contract.md。周报发布异常另读weekly-publication.md，不把仓库/URL/篇幅/研究对象写入本通用索引。

每次处置记录：症状、当前run持久证据、必要性/严重级别、第一处未验证边界、终态。

- **子会话failed/unknown但文件存在，或缺final/完成事件**：执行主文件第3节“文件完整但标记缺失/子状态failed”条件，不盲目重派；先确认写入者状态与内容版本，不能因为会话success跳过语义验收。
- **WAIT_TIMEOUT**：按第3节做独立文件检查、读进度，再依据剩余预算决定；不将工具exit0误作交接通过。
- **wait控制进程异常**：先确认原进程是否结束，复核当期产物，不kill健康等待、不再并发启动相同wait。
- **路径不符/过期标记**：对照明确清单与run映射，身份或来源不能确证则BLOCKED；不以广泛历史扫描猜路径。只有新逻辑运行目录要求初始为空，恢复保留原目录和证据。
- **辅助诊断/通知失败**：按第7节单独WARNING，保留已验证发布；不运行“成功命令”盖错。
- **原生运行error但产物已完成，且错误文本指向异步媒体任务**：按主文件第5节确认是否父级直调异步生图使完成唤醒撞上活跃回合；按第7节把原生运行失败与已验证的内容/构建/Git/HTTP结果分开记录，不重做已完成工作。
- **Git不确定或检查中有并发变化**：按helper契约验证live remote及前后快照。停止冲突操作，不强推、reset、stash或改历史；稳定后只复验未验证边界，不重复已同步提交。
- **HTTP暂不可用**：按业务有界重试，公网安全检查不可关闭。必要HTTP边界未过记BLOCKED并保留Git PASS，不再次发布；非必要项才可WARNING/N/A。
- **宿主重启/进程突停**：沿用原run，重验文件版本与已触及的外部边界，从第一处未验证阶段继续。不能声称此文件会自动触发恢复。
- **工具降级**：只使用已批准替代路径，记录差异，不弱化必须通过的验收条件。

症状索引不授权业务重试、模型/主机配置变更或生成替代执行器。新增模式必须可复用于多种长任务；具体研究、发布和交付规则归任务Prompt或已明确选用的专项参考。
